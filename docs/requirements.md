# 需求规格

> 本文件是项目需求的唯一事实来源，开发与验收均以此为准。

## 1. 总目标

自研一台 6 轴桌面级机械臂，支持关节运动与末端夹爪抓取，总预算约 3500 元。

## 2. 功能需求

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-01 | 6 轴运动 | P0 | 各关节可独立运动，精度达到设计值 |
| FR-02 | 末端夹爪抓取 | P0 | 可抓取小型物体 |
| FR-03 | 上位机控制 | P0 | CLI-Tool 可连接并下发指令 |
| FR-04 | 姿态感知（IMU） | P1 | 主控可读取 MPU6050 数据 |

## 3. 非功能需求

- 预算：≤ 3500 元（跟踪见 `bom.md`）
- 结构：3D 打印件 / 亚克力，不使用 CNC
- 控制：Dummy 开源固件 + STM32 主控 + 电机驱动板

## 4. 约束

- 上游源码位于 `~/Dummy-Robot`，本仓库不重复存放。
- 对上游的修改必须以补丁形式记录于 `firmware/patches/`。
